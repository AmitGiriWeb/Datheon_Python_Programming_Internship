# Hangman Game in Python

This is a simple terminal-based Hangman game developed using Python. The player must guess the hidden word within 6 incorrect attempts.

## Features

- Random word selection
- Letter-by-letter guessing
- ASCII gallows art
- Tracks guessed letters
- Prevents duplicate penalties
- Win or lose messages

## Technologies Used

- Python 3
- Random module

## How to Run

1. Install Python 3.
2. Open the project in VS Code.
3. Run the following command:

```bash
python hangman.py
```
